Pour Nine

Pour the colours between glasses until each one holds a single shade.

The glasses start mixed up. Tap one to pick it up, tap another to pour — the top colour flows across as long as there is room and the colours match. Get every glass to one shade and the level is done.

No timer. Works offline. Free.
